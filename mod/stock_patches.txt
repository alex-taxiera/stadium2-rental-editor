# The same screen gives each trainer a title, under the picture: a text of bank 0x48 by
# number. A human's is always 0x29, POKeMON TRAINER, in func_826053A4 before a battle and
# func_82605908 after one. Both now take it from the port's byte of gTrainerTitles, which
# holds the number XOR 0x29, so that a byte nobody has set gives the same title as before.
# Each already has the port in hand to tell a human from the COM, which keeps its own.
#
# The byte is only read once the port is known not to be negative. 0x80000000 plus -1 is
# 0x7FFFFFFF, and an address worked out from that is not sign-extended from 32 bits, which
# this processor answers with an address error: the first version of this patch read the
# byte before the test and hung the screen on the COM's side.
